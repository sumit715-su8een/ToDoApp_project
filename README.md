# ToDoApp_project

A simple To-Do application with a complete CI/CD pipeline.

## App
Flask-based REST API for managing to-do items.

## CI/CD Pipeline (GitHub Actions)
- **Lint**: flake8 code quality check
- **Test**: pytest unit tests
- **Build**: Docker image build with layer caching
- **Deploy**: Auto-deploy to staging on main push
- **Notify**: Slack alert on pipeline failure
